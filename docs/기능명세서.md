## 1. 제품 개요

3Monster 패밀리 **카페 모듈스터(CafeMonster)** 제품군으로 등록된 3개의 크롬 제품을 공유하는 Streamlit 멀티페이지 앱입니다.

- **형태:** Streamlit 멀티페이지 앱. 진입 스크립트 `run_app.py`가 포트를 잡고 Streamlit을 띄우며, **pywebview** 또는 시스템 브라우저로 UI를 표시합니다.
- **크롤링:** Selenium 기반 네이버 카페 (`app/products/scraper/crawler.py`).
- **설정:** 윈도우 시스템 공통 경로 `%APPDATA%/CafeScraper/user_settings.json` 에 독립되어 저장됩니다.
- **데이터:** Zero-maintenance Data Policy에 따라 최상위 고정 절대 경로인 `내 문서\MarketingMonster\CafeScraper` 에 저장 및 누적(Piling)되며, 원본 SQLite DB는 `DB/` 하위에, 로그는 `Logs/` 하위에 은닉됩니다. 수집 완료 시 원본 DB의 각 테이블은 식별 명확화를 위해 `[수집형태]_[테이블명]_[카페명]_[시작일]~[종료일].csv` 형태로 자동 변환되어 최상위 폴더에 저장됩니다.

## 3. 카페 메인 수집 (`app.py`)

- **product_id**: `CafeCrawler`
- 카페 URL, 게시판 다중 선택, 수집 기간, 시작 페이지, 관리자 닉·제외 게시판 등.
- 수집 모드: 본문+댓글 / 본문만 등 (UI·크롤러 옵션과 연동).
- **자동 로그인:** 설정의 네이버 ID/PW·`auto_login_enabled` 및 `app/utils/naver_login.py`.
- **DB 및 초기화:** `resolve_db_path` → `init_db`로 `posts` / `comments` 관리. `[통계 초기화 후 작업하기]` 버튼 제공 (기존 데이터 삭제 없이 새 DB를 생성해 화면 통계 및 작업 환경 초기화).
- 로그: `get_logs_dir()` → `logs/`.

## 4. 이벤트 활동 분석기 (`pages/03_event_comment_lottery.py`)

- **product_id**: `EventStats`
- **DB 및 초기화:** `resolve_event_db_path` → `init_event_db`. `[통계 초기화 후 작업하기]` 버튼 제공 (기존 데이터 삭제 없이 새 DB를 생성해 화면 통계 및 작업 환경 초기화).
- **회원 활동지수 집계 (핵심):** 이벤트 기간내 댓글/게시글/방문수 등 수집 데이터를 기반으로 회원별 활동 점수를 산정하고 랭킹화.
- **조건1:** 댓글 기반 수집·필터·티켓 산정(글자 수·미디어 보너스 등, 설정 키 `event_comment_*` 등).
- **조건2:** 게시글 기반 분석·티켓 (`event_post_*`, `event_post_analysis` 등).
- **멘토:** `event_mentor_*` 설정 및 `event_mentor_visits` 테이블.
- **작업 완료 후**: 추첨·후보 표시·데이터 초기화 등 UI는 동일 페이지에서 처리.

(세부 수식·엣지케이스는 해당 페이지·`event_db.py` 로직을 단일 근거로 둡니다.)

## 5. 자동댓글러 (`pages/04_auto_commenter.py`)

- **product_id**: `AutoComment`

- 카페·게시판·기간·제외 닉 등으로 **타겟 글** 수집.
- **DB 및 초기화:** `resolve_commenter_db_path` → **`init_event_db` 동일 스키마** (타겟은 `commenter_targets`). `[통계 초기화 후 작업하기]` 버튼 제공 (기존 데이터 삭제 없이 새 DB를 생성해 화면 통계 및 작업 환경 초기화).
- 댓글 시도 후 `comment_status`, `comment_detail`, `comment_tried_at` 갱신.
- 2단계 **목록 재수집** 시에도 같은 URL 행은 `replace_commenter_targets`가 **기존 댓글 시도 결과**(`comment_*`)를 이어 받음(무조건 초기화되지 않음).
- **📋 타겟 목록:** 재수집 없이 **글 작성일**(선택)만 골라 표·실행 대상 줄임 — **전체**로 원복. 세션 때문에 표가 비어 보여도 **`commenter_targets` DB 기준 자동 재보충**(1.3.28) 시도.
- 입력 폼에서 Enter로 인한 불필요 rerun 방지 등 UX 처리 포함.

## 6. 빌드·배포

- **`version.txt`:** 한 줄 semver (예: `1.3.8`).
- **`build.bat`:** PyInstaller 빌드. **`dist\cafescraper_V{semver}\data`** 또는 예전 레이아웃 **`dist\CafeScraper\data`** 가 있으면 `dist\_user_data_backup` 으로 백업한 뒤, 새 빌드 폴더 `dist\cafescraper_V{semver}\` 로 복원합니다.
- **배포 ZIP (Clean Packaging Policy 준수):** `pack_dist.ps1`이 **`data`**, **`user_settings.json`**, **`comment_templates.json`** 및 기타 소스 파일, 배치 파일 등을 압축 대상에서 원천 배제합니다. 사용자가 압축을 풀었을 때 루트 폴더에는 **`CafeScraper.exe` 단일 실행 파일과 `_internal` 폴더만 노출**되도록 하여 시각적 단순함과 유출 방지를 극대화합니다.
- **산출물:** **`dist/cafescraper_V{semver}/`** (폴더명·ZIP 접두는 루트 `version.txt` semver와 맞춤), 루트 **`cafescraper_V{semver}.zip`**. 배포물 옆에 `version.txt`를 복사하지 않습니다(CHANGELOG 1.3.21).

## 7. 설정 파일(`user_settings.json`) 개요

로컬 경로·계정·카페 URL 등 **민감 정보**가 들어갈 수 있어 **저장소에 커밋하지 않는 것**이 안전합니다. 주요 그룹만 기술합니다.

- **메인 카페:** `cafe_url`, `cafe_name`, `db_path`, `exclude_boards`, 날짜·`extracted_boards`·`selected_board_urls` 등.
- **이벤트:** `event_*` (카페 URL, 게시판, 기간, 딜레이, 제외 닉, DB 경로, 조건·티켓·멘토 관련 플래그·숫자).
- **자동 댓글러:** `commenter_*` (DB 경로, 카페, 게시판, 간격·로그인 등).

## 9. 주요 기술 업그레이드 사항 (v1.3.32 ~ v1.3.48)

### 네이버 카페 크롤링 엔진 최적화 & SPA/PC 호환성 개선
- **페이지네이션 리다이렉트 지연 제거:** 페이지 이동 시 매번 최상위(Top-level) 브라우저 창을 리다이렉션하여 발생하던 40초 상당의 로딩 지연을 해결했습니다. 이미 카페에 진입해 있는 경우, `cafe_main` iframe 내부에서 직접 JavaScript (`location.href`)를 실행하여 페이지를 이동하도록 전환함으로써 로딩 안정성과 속도를 크게 개선했습니다.
- **SPA 및 Legacy URL 규격 상호 파싱 정교화:** 네이버 카페의 신형 SPA URL 구조(`/ca-fe/`, `/f-e/`)와 구형 Legacy URL 구조(`ArticleList.nhn`) 간 변환 로직을 통합 및 정교화했습니다.
- **PC 모드 iframe 전환 로직 안정화:** PC 브라우저 환경에서 SPA 스타일 URL에 대응할 때도 `cafe_main` iframe으로 정상 전환할 수 있도록 수집 차단이나 빈 목록 수집 문제를 근본적으로 예방했습니다. iframe 내부의 흰 화면(Blank Page) 로딩 현상을 방지하도록 상황별 최적의 URL 패턴을 동적으로 조립합니다.

### 백그라운드 태스크 및 세션/로그 안정성 고도화
- **자동댓글러 백그라운드 스레드 수집 연동 (v1.3.33):** 타겟 목록 수집을 백그라운드 스레드 방식으로 전환하여, 대량 수집 시에도 프로세스가 안정적으로 구동되며 실시간 진행률 데이터가 세션에 동기화되도록 개선했습니다.
- **이벤트 댓글 조건(3) 방문수 백그라운드 수집 연동 (v1.3.34):** 등급별 방문수를 수집할 때 누적 수집 행 수와 경과 시간을 실시간 추적하고 세션 데이터로 전달되도록 연동했습니다.
- **네이버 로그인 세션 바인딩 안정화 (v1.3.35):** 아이디/비밀번호 입력 중 세션 리런(rerun) 시 로그인 설정 세션 상태가 리셋되어 입력 포커스가 상실되거나 설정 창이 닫히는 오작동 문제를 세션 상태 바인딩으로 해결했습니다.
- **수집 예외 로그 고도화 (v1.3.39):** 별명 필터 등으로 수집 대상에서 스킵되는 게시글의 식별 정보(작성자명 등)가 로깅되도록 보완했습니다.

## 10. 카페스탭 ID 수집 (`pages/05_leader_marketer.py`)

- **기능 개요:** 하나 이상의 네이버 카페 목록을 직접 입력하거나, 특정 키워드를 입력해 검색된 네이버 카페 목록을 소스로 삼아 카페 매니저/스태프(스탭) 목록의 네이버 ID 및 이메일을 일괄적으로 자동 추출하고, 랜덤 지연 발송을 적용해 대량의 자동 쪽지(Selenium) 또는 이메일(SMTP)을 백그라운드로 자동 발송하는 마케팅 자동화 기능.
- **수집 모드:**
  1. **직접 입력 모드:** 여러 개의 카페 주소 또는 영문 ID를 한 줄에 하나씩 다량 입력하여 순차 추출을 개시합니다.
  2. **키워드 검색 모드:** 네이버 검색 엔진에 키워드를 던져 검색 결과(start=1, 16, 31 대역)를 BeautifulSoup 라이브러리로 초고속 수집 및 고유 카페 ID 목록을 자동 가공한 뒤, 이를 소스로 활용해 각 카페의 스탭 ID 추출을 전자동으로 실행합니다.
- **추출 메커니즘:**
  1. 각 대상 카페에 순차적으로 접속하여 `g_sClubId`를 추출해 고유 ID 획득.
  2. "카페소개" 탭 진입 JavaScript 실행을 통해 소개 iframe 내에 스태프 리스트 돔(DOM)을 로딩.
  3. 셀레늄 DOM 직렬화 버그(`Cannot convert object to primitive value`)를 우회하고자, 자바스크립트로 HTML 돔에 임시 hidden input을 생성하여 값을 텍스트 스트링(`nick^role^id_attr|`) 형태로 보관한 뒤 파이썬에서 해당 attribute 값을 읽어오는 **DOM 주입 void 리턴 우회 기법** 적용.
  4. 클릭 제어를 통해 프로필 레이어 팝업을 띄우고, 각 스태프의 고유 네이버 ID(member_id)를 복구해 이메일(`ID@naver.com`) 목록 생성.
- **저장 및 탐색기 연동:** 수집 즉시 사용자 표준 다운로드 폴더(`Downloads`)에 `{검색어/직접입력}_스탭_이메일_목록.csv` 파일로 자동 저장하고, 윈도우 탐색기(`explorer`)를 자동 기동 및 포커싱하여 사용자가 즉시 엑셀 파일을 열어볼 수 있도록 유도.
- **발송 및 방어 제어:**
  - **쪽지 자동 발송:** 추출된 스태프 ID 리스트에 대해 `https://note.naver.com/note/write.nhn?targetUserId={ID}` 주소로 이동하여 제목, 내용 입력 및 전송 버튼 클릭 후 Alert 수락까지 자동 처리.
  - **이메일 자동 발송:** 가계정 발송에 특화된 SMTP 직접 로그인 방식을 지원하며, Naver SMTP(`smtp.naver.com:465`) 연동 시 2차 앱 비밀번호 등으로 이메일 자동 일괄 발송 처리.
  - **루즈한 딜레이:** 사용자가 설정한 랜덤 딜레이(예: 30초~120초) 내에서 무작위 대기(Jitter)를 적용하여 봇 감지 및 차단 리스크 최소화.
  - **백그라운드 스레드:** Streamlit 세션 리런 및 새로고침 영향 없이 백그라운드 스레드(`threading.Thread`)로 안전하게 추출 및 발송 태스크가 구동되며, 대시보드 내 무제한 스크롤 로그 박스로 진행 실시간 모니터링 가능.
