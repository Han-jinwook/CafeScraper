# CafeScraper 기능 명세

| 항목 | 값 |
|------|-----|
| **제목** | CafeScraper 기능 명세 |
| **버전** | 1.3.45 (`version.txt`) |
| **일시** | 2026-06-15 |

이 문서는 **현재 코드베이스** 기준으로 유지합니다. 릴리스마다 `version.txt`와 표의 버전·일시를 맞춥니다.  
DB 상세는 `docs/architecture/schema.md`, 인수인계·이슈 메모는 `docs/help.md`를 참고합니다.

---

## 1. 제품 개요

- **형태:** Streamlit 멀티페이지 앱. 진입 스크립트 `run_app.py`가 포트를 잡고 Streamlit을 띄우며, **pywebview** 또는 시스템 브라우저로 UI를 표시합니다.
- **크롤링:** Selenium 기반 네이버 카페·위키 등 (`app/products/scraper/crawler.py`).
- **설정:** 프로젝트 루트 `crawler_config.json` (`app/utils/paths.py` → `get_config_path()`).
- **데이터:** SQLite 여러 파일로 역할 분리 (경로·환경 변수는 schema 문서 참고).

---

## 2. 화면(페이지) 구성

| Streamlit | 파일 | 역할 |
|-----------|------|------|
| 홈(카페 수집) | `app.py` | 네이버 카페 게시판 스캔, 게시글·댓글 수집, DB 저장, 자동 로그인 등 |
| 이벤트 댓글·추첨 | `pages/03_event_comment_lottery.py` | 이벤트 기간 댓글/글 수집, 조건·티켓·멘토·추첨 UI |
| 자동 댓글러 | `pages/04_auto_commenter.py` | 게시판 스캔, 타겟 수집, 댓글 작성 자동화 |

상단 가로 내비: `.streamlit/config.toml`에서 사이드바 네비 숨김, `app/utils/streamlit_top_nav.py` 등으로 통일.

---

## 3. 카페 메인 수집 (`app.py`)

- 카페 URL, 게시판 다중 선택, 수집 기간, 시작 페이지, 관리자 닉·제외 게시판 등.
- 수집 모드: 본문+댓글 / 본문만 등 (UI·크롤러 옵션과 연동).
- **자동 로그인:** 설정의 네이버 ID/PW·`auto_login_enabled` 및 `app/utils/naver_login.py`.
- **DB:** `resolve_db_path` → `init_db`로 `posts` / `comments` 초기화.
- 로그: `get_logs_dir()` → `logs/`.

---

## 4. 이벤트 댓글·추첨 (`pages/03_event_comment_lottery.py`)

- **DB:** `resolve_event_db_path` → `init_event_db`.
- **조건1:** 댓글 기반 수집·필터·티켓 산정(글자 수·미디어 보너스 등, 설정 키 `event_comment_*` 등).
- **조건2:** 게시글 기반 분석·티켓 (`event_post_*`, `event_post_analysis` 등).
- **멘토:** `event_mentor_*` 설정 및 `event_mentor_visits` 테이블.
- 추첨·후보 표시·데이터 초기화 등 UI는 동일 페이지에서 처리.

(세부 수식·엣지케이스는 해당 페이지·`event_db.py` 로직을 단일 근거로 둡니다.)

---

## 5. 자동 댓글러 (`pages/04_auto_commenter.py`)

- 카페·게시판·기간·제외 닉 등으로 **타겟 글** 수집.
- **DB:** `resolve_commenter_db_path` → **`init_event_db` 동일 스키마** (타겟은 `commenter_targets`).
- 댓글 시도 후 `comment_status`, `comment_detail`, `comment_tried_at` 갱신.
- 2단계 **목록 재수집** 시에도 같은 URL 행은 `replace_commenter_targets`가 **기존 댓글 시도 결과**(`comment_*`)를 이어 받음(무조건 초기화되지 않음).
- **📋 타겟 목록:** 재수집 없이 **글 작성일**(선택)만 골라 표·실행 대상 줄임 — **전체**로 원복. 세션 때문에 표가 비어 보여도 **`commenter_targets` DB 기준 자동 재보충**(1.3.28) 시도.
- 입력 폼에서 Enter로 인한 불필요 rerun 방지 등 UX 처리 포함.

---

## 6. 빌드·배포

- **`version.txt`:** 한 줄 semver (예: `1.3.8`).
- **`build.bat`:** PyInstaller 빌드. **`dist\cafescraper_V{semver}\data`** 또는 예전 레이아웃 **`dist\CafeScraper\data`** 가 있으면 `dist\_user_data_backup` 으로 백업한 뒤, 새 빌드 폴더 `dist\cafescraper_V{semver}\` 로 복원합니다.
- **배포 ZIP:** `pack_dist.ps1`이 **`data`**, **`crawler_config.json`**, **`comment_templates.json`**을 ZIP에서 제외합니다(DB·로컬 설정 유출 방지). 엔드유저는 기존 설치 폴더의 `data`/설정을 유지한 채 exe만 교체하면 됩니다.
- **산출물:** **`dist/cafescraper_V{semver}/`** (폴더명·ZIP 접두는 루트 `version.txt` semver와 맞춤), 루트 **`cafescraper_V{semver}.zip`**. 배포물 옆에 `version.txt`를 복사하지 않습니다(CHANGELOG 1.3.21).

---

## 7. 설정 파일(`crawler_config.json`) 개요

로컬 경로·계정·카페 URL 등 **민감 정보**가 들어갈 수 있어 **저장소에 커밋하지 않는 것**이 안전합니다. 주요 그룹만 기술합니다.

- **메인 카페:** `cafe_url`, `cafe_name`, `db_path`, `exclude_boards`, 날짜·`extracted_boards`·`selected_board_urls` 등.
- **이벤트:** `event_*` (카페 URL, 게시판, 기간, 딜레이, 제외 닉, DB 경로, 조건·티켓·멘토 관련 플래그·숫자).
- **자동 댓글러:** `commenter_*` (DB 경로, 카페, 게시판, 간격·로그인 등).

## 9. 주요 기술 업그레이드 사항 (v1.3.32 ~ v1.3.45)

### 네이버 카페 크롤링 엔진 최적화 & SPA/PC 호환성 개선
- **페이지네이션 리다이렉트 지연 제거:** 페이지 이동 시 매번 최상위(Top-level) 브라우저 창을 리다이렉션하여 발생하던 40초 상당의 로딩 지연을 해결했습니다. 이미 카페에 진입해 있는 경우, `cafe_main` iframe 내부에서 직접 JavaScript (`location.href`)를 실행하여 페이지를 이동하도록 전환함으로써 로딩 안정성과 속도를 크게 개선했습니다.
- **SPA 및 Legacy URL 규격 상호 파싱 정교화:** 네이버 카페의 신형 SPA URL 구조(`/ca-fe/`, `/f-e/`)와 구형 Legacy URL 구조(`ArticleList.nhn`) 간 변환 로직을 통합 및 정교화했습니다.
- **PC 모드 iframe 전환 로직 안정화:** PC 브라우저 환경에서 SPA 스타일 URL에 대응할 때도 `cafe_main` iframe으로 정상 전환할 수 있도록 수집 차단이나 빈 목록 수집 문제를 근본적으로 예방했습니다. iframe 내부의 흰 화면(Blank Page) 로딩 현상을 방지하도록 상황별 최적의 URL 패턴을 동적으로 조립합니다.

### UI/UX 안정성 및 백그라운드 태스크 모니터링 강화
- **상단 메뉴바 밀착 및 가이드 2단 레이아웃 개편 (v1.3.45):** Streamlit 1.39의 신규 투명 헤더 바(`stAppHeader`)와 사이드바 제어 버튼(`collapsedControl`)을 완벽히 차단하여 상단 투명 공백을 Zero(0px)화했고, 본문 상단 패딩을 `0.5rem`으로 줄였습니다. 또한, 사용 가이드 부분을 별도 행의 expander 구조 대신 타이틀 우측에 가이드 버튼을 배치하여 클릭 시 좌우 `[1:3]` 비율로 타이틀과 가이드 카드가 한 행에 정렬되도록 개편하여 불필요한 2줄 낭비를 해결하고 화면 밀착감을 극대화했습니다.
- **초기 로딩 화면 잔상 개선 (v1.3.40):** 앱 최초 실행 시 1~2초 동안 Streamlit 기본 사이드바 네비게이션과 로딩 스켈레톤 화면이 나타났다 사라지는 UI 잔상 현상을 Streamlit 템플릿 CSS 주입 방식으로 완벽하게 차단했습니다.
- **자동댓글러 백그라운드 수집 연동 (v1.3.33):** 타겟 목록 수집 시 유발되던 UI 프리징(화면 멈춤)을 방지하기 위해, 크롤링 작업을 백그라운드 스레드 및 실시간 진행률 프로그레스 바 UI 연동 방식으로 전면 개편했습니다.
- **이벤트 댓글 조건(3) 모니터링 개선 (v1.3.34):** 등급별 방문수를 단독 수집할 때도 UI가 굳지 않고 실시간 수집 등급, 누적 수집 행 수, 경과 시간이 정상 표시되도록 진행률 바 및 전용 콜백 모니터링을 연동했습니다.
- **네이버 로그인 UI 보정 (v1.3.35):** 아이디/비밀번호 입력 도중 포커스가 바뀌었을 때 로그인 설정 expander 접기/펼치기 창이 비자발적으로 닫히던 세션 연동 오작동 문제를 세션 상태 바인딩으로 해결했습니다.
- **스킵 로그 구체화 (v1.3.39):** 별명 필터(포함/제외)에 의해 게시글이 스킵될 때, 생략된 대상이 직관적으로 드러나도록 로그에 실제 작성자명을 기록하여 분석 가시성을 향상했습니다.
