## 현재 남은 핵심 이슈 (UI)

`수집 조건` 내부 헤더에서 **제목 + 체크박스 정렬**이 아직 완전히 자연스럽지 않음.

사용자 요구:
- 섹션 제목 옆에 체크박스가 붙어야 함
- 제목이 줄바꿈되거나 찌그러지면 안 됨
- `선택` 텍스트 라벨은 제거
- 전체가 단정하게 한 줄 정렬되어야 함
