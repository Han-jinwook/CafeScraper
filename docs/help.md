---

## 현재 핵심 이슈

`카페명`, `카페 URL` 입력창의 **이전 입력값 추천 드롭다운 UX가 불안정**함.

- 사용자 요구 UX:
  - 입력창은 기존처럼 1개만 유지
  - 입력칸에 포커스하면 이전 저장값(최대 5개) 보임
  - `네이버 아이디/비번`에는 추천이 뜨면 안 됨
  - 수집/이벤트 페이지 동작이 동일해야 함

- 실제 문제:
  - 어떤 시도에서는 엉뚱한 추천값(브라우저 자동완성) 노출
  - 어떤 시도에서는 아무 추천도 안 뜸
  - 화살표 유무/추천 동작이 페이지별로 불일치 발생

---

## 재현 포인트

1. `카페 수집` 또는 `이벤트 댓글 분석` 페이지 진입
2. `카페명`, `카페 URL` 저장 후 리셋
3. 다시 입력칸 포커스
4. 기대: 저장값 추천 표시 / 실제: 안 뜨거나 엉뚱한 추천 노출
