## 🚨 문제 상황: 등급 보강 실패
- **증상**: 크롤링은 정상 작동하나, `member_level`이 수집되지 않고 공백으로 남음
- **로그**: `⚠️ 등급 미확보: ...` 또는 `⚠️ 등급 보강 실패: ... has no attribute 'get_article_member_level'`
- **원인**:
  1. `app.py`에서 `get_article_member_level` 메서드를 호출하지만,
  2. 세션(`st.session_state.crawler`)에 저장된 객체가 **해당 메서드가 없는 구버전 클래스 인스턴스**인 상태로 남아있음.
  3. API가 간헐적으로 비어있는 값을 줄 때, 상세 페이지 폴백(2차 시도)이 없었음 (이건 직전에 코드로 복구함).
