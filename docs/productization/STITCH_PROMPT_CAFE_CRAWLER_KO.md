## [복사 시작]

### 역할
너는 **B2B/프로슈머용 데스크톱 웹앱** UI·UX 전문가다. 첨부한 스크린샷은 **Streamlit 기반 프로토타입**이며, 레이아웃·정보 구조는 참고하되 **시각·간격·계층·트렌드**는 전면 개선한다.

### 우산 브랜드
**3Monster** — 하위: **카페 몬스터**(이번 시안) / **마케팅 몬스터**(사이트·sitemap·RSS) / **앱 몬스터**(예정).  
(`docs/productization/BRAND_GUIDE_3MONSTER.md` 참고)

### 제품 한 줄
**「카페 몬스터」카페 크롤러** — 네이버 카페에서 지정 게시판·기간 기준으로 게시글·댓글을 수집해 로컬 DB에 저장하는 **윈도우 사용자용** 도구.

### 사용자
- 카페 운영자, 마케터, 리서처(비개발자 포함)
- 한국어 UI, **긴 작업(크롤링) 중에도 상태가 한눈에 보여야** 함

### 브랜드 톤 (가이드 반영)
- 시리즈명: **카페 몬스터 (CafeMonster)** — 친근하지만 가벼우면 안 됨, **신뢰·속도·통제감**
- 키 컬러는 **짙은 네이버 그린에 가깝되 완전 복제 금지** — 차별화된 1차 색 + 중립 그레이 스케일
- 아이콘: 이모지 남발 대신 **단순 라인 아이콘** 또는 최소 이모지

### 디자인 방향 (2025–2026 트렌드)
- **심플**: 사이드바 설정 vs 메인 작업·현황의 **2컬럼** 유지, 불필요한 장식 제거
- **밀도 조절**: 설정은 **카드/섹션**으로 묶고, 실행 중에는 **진행률·예상·중단**이 최상단 고정
- **가독성**: 숫자(건수, 페이지, 소요시간)는 **탭ular 숫자감**, KPI는 **큰 숫자 + 보조 설명**
- **접근성**: 대비 AA 이상, 포커스 링, 중요 버튼 **1개만 primary**
- **다크모드 옵션** (선택) — 라이트 기본

### 화면 우선순위 (스크린샷 순서대로 커버)
1. **메인 — 크롤 설정 + 실행**
   - 카페 URL, 게시판 목록 가져오기, 체크박스 다중 선택, 날짜 범위, DB 경로
   - **시작 ↔ 중단** 토글 명확, 실행 중 비활성화할 항목 시각적 구분
2. **실행 중 — 라이브 대시보드**
   - 현재 게시판, 진행 페이지/게시글 수, 예상 시간(있다면), 에러·경고 한 줄
3. **완료/로그**
   - 요약 카드 + 접기 가능한 상세 로그

### UX 원칙 (반드시 반영)
- **실수 방지**: 파괴적 동작(전체 재수집 등)은 확인 모달 또는 2단계
- **긴 작업**: 중단은 항상 보이게, “멈춘 것처럼 보임” 방지용 **스켈레톤/펄스** 제안
- **모바일**: 1차 타깃은 데스크톱 — 단 **최소 1280px 너비** 기준 반응형만 언급

### 기술 제약 (디자인 전달 시 명시)
- 실제 구현은 **Streamlit** 가능성이 높음 → **커스텀 CSS 한계**가 있으므로, 과도한 애니메이션·복잡한 그리드는 피하고 **구현 가능한 컴포넌트 단위**로 설계
- 산출물에 **색상(hex)·타이포 스케일·라운드·그림자·간격 8px 그리드**를 코드/토큰 형태로 적어줄 것

### 산출물 요청
1. **메인 화면** 와이어프레임 1장 + **하이파이** 1장  
2. **실행 중** 하이파이 1장  
3. **디자인 시스템** 미니 가이드: Primary/Secondary/Surface/Error, 버튼·입력·카드 상태(hover/disabled)  
4. 한국어 **라벨 예시** (버튼명: 예) `게시판 목록 가져오기`, `수집 시작`, `수집 중지`)

### 금지
- 실제 네이버 로고·공식 UI **도용 금지** (유사 톤만)
- “모든 사이트 크롤” 등 **기능 과장 문구** 넣지 말 것

### 첨부 스크린샷에 대해
이 이미지들은 **현재 프로토타입**이다. 정보 구조는 유지하되, **시각적 품질·계층·여백·타이포**는 너의 제안으로 바꿔도 된다.
